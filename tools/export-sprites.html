⚗ HEXBOUND — SPRITE EXPORTER

Download the current placeholder sprites as PNGs. Edit them in Aseprite, LibreSprite, or any pixel art tool.
Save back to the same path shown under each sprite, refresh the game — your art loads automatically.
Each image must keep the exact same pixel dimensions shown below.
HOW TO REPLACE A SPRITE:
1. Click Download under the sprite you want to edit.
2. Open in Aseprite (or similar). The canvas size is fixed — do not resize it.
3. For animated sprites: each frame is side-by-side horizontally. Edit each frame in sequence.
4. Export/Save As → PNG → replace the file at the assets/sprites/… path shown.
5. Hard-refresh the game (Cmd+Shift+R) — your art is live.
Missing files fall back to the built-in procedural art automatically.
