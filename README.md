# Spooky Sorcerer Game (8-Bit Side-Scrolling Platformer)

A premium retro platformer browser game.

## Story
A brave sorcerer seeks to destroy an evil necromancer in a spooky castle who has been raising the dead. Rescue townspeople and civilians along the way!

## Technical Stack
- Custom 2D HTML5 Canvas engine
- Vanilla ES6 Javascript
- Custom pixel-perfect 8-bit styling and animations

## How to Play
- **A/D** or **Left/Right**: Move
- **W** or **Up**: Jump
- **Space** or **J**: Cast Spells
- **E** or **Enter**: Interact with civilians
